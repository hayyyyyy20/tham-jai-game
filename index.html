อริยสัจ 4
ทุกข์ = ปัญหา/สภาพที่ทนได้ยาก • สมุทัย = สาเหตุ • นิโรธ = ความดับทุกข์ • มรรค = แนวทางปฏิบัติเพื่อดับทุกข์
มรรคมีองค์ 8
สัมมาทิฏฐิ ความเห็นชอบ • สัมมาสังกัปปะ ความดำริชอบ • สัมมาวาจา พูดชอบ • สัมมากัมมันตะ กระทำชอบ • สัมมาอาชีวะ เลี้ยงชีพชอบ • สัมมาวายามะ เพียรชอบ • สัมมาสติ ระลึกชอบ • สัมมาสมาธิ ตั้งจิตมั่นชอบ
ศีล 5
ไม่ฆ่าสัตว์ • ไม่ลักทรัพย์ • ไม่ประพฤติผิดในกาม • ไม่พูดเท็จ • ไม่ดื่มสุราและของมึนเมา
พรหมวิหาร 4
เมตตา = ปรารถนาให้ผู้อื่นมีความสุข • กรุณา = ช่วยเมื่อผู้อื่นทุกข์ • มุทิตา = ยินดีเมื่อผู้อื่นได้ดี • อุเบกขา = วางใจเป็นกลางอย่างมีเหตุผล
อิทธิบาท 4
ฉันทะ = พอใจในสิ่งที่ทำ • วิริยะ = เพียร • จิตตะ = เอาใจใส่ • วิมังสา = คิดพิจารณา ตรวจสอบ และปรับปรุง
สังคหวัตถุ 4
ทาน = ให้/แบ่งปัน • ปิยวาจา = พูดดี • อัตถจริยา = ทำตนให้เป็นประโยชน์ • สมานัตตตา = วางตนสม่ำเสมอเสมอต้นเสมอปลาย
กฎแห่งกรรม + บุญกิริยาวัตถุ 3
การกระทำมีผลตามเหตุปัจจัย • บุญกิริยาวัตถุ 3 ได้แก่ ทาน ศีล และภาวนา
ไตรสิกขา
ศีล = ฝึกกายและพฤติกรรม • สมาธิ = ฝึกจิตให้มั่นคงสงบ • ปัญญา = ฝึกคิดและเข้าใจความจริง
